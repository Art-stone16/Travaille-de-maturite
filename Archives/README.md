# Archives du projet

Ce dossier contient les anciens éléments que tu as choisi de conserver après le
tri du projet. Il ne s'agit plus d'une liste de fichiers à vérifier ou à
supprimer.

Le dossier contient notamment :

- `modeles/modeles_historiques/` : anciens modèles Keras ;
- `sorties/graphiques/` : anciennes courbes d'entraînement ;
- `sorties/matrices_confusion/` : anciennes évaluations ;
- `sorties/tests_condition_reelle/` : anciens essais sur photographies.

Les scripts actuels ne lisent ni n'écrivent automatiquement dans `Archives/`.
Ce dossier sert uniquement de mémoire historique du projet.

Les modèles `.keras` et les résultats historiques conservés ici sont publiés
sur GitHub afin de documenter l'évolution du projet.
