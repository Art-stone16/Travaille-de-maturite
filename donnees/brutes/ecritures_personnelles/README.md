# Écritures personnelles isolées

Place ici les images utilisées pour la superposition avec les chiffres moyens
MNIST. Chaque fichier doit contenir un seul chiffre, bien cadré, avec un trait
noir sur un fond clair.

Exemples de noms : `mon_2.JPG`, `mon_7.JPG`, `essai_fin_9.png`.

Ces fichiers sont lus par `scripts/visualisation/analyser_chiffres_moyens.py` avec une option
comme `--personnel 7=donnees/brutes/ecritures_personnelles/mon_7.JPG`.
